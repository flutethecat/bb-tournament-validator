**🎲 FUMBBL40k — How to Set Up a Game**
*Needs a **v0.2.0+** build. Use your real FUMBBL coach name so opponents recognise you.*

**1️⃣ Point at the fork**
Open the **Game Browser** → click **FUMBBL40k** → set the **fork IP** (the one the organiser gives you; use `127.0.0.1` if you run the fork on your own machine) → **Set IP**.

**2️⃣ Register (first time only)**
**Settings → Connection → FUMBBL40k → Register** → your **FUMBBL name** + a **password you choose** (does NOT have to match your FUMBBL password).

**3️⃣ Add a team to your library**
**Create Game → Ingest Team** → paste a FUMBBL **team id or URL** (e.g. `1263233` or `https://fumbbl.com/t/1263233`).
⚠ A freshly ingested team is playable **after the next fork restart** — ping the organiser if you can't join with it yet.

**4️⃣ Challenge an opponent**
**Create Game** → type your **opponent's name** (pick from the list) → **Choose team** → **Create Game**. You'll see **"Waiting for &lt;opponent&gt;…"**.

**5️⃣ The game starts when you BOTH challenge each other** 🎉
Coordinate first (here in Discord): you name them, they name you. Order doesn't matter — whoever's second launches the match for both of you.

**❓ Trouble?**
• *"config-web unreachable"* → the Bot server isn't reachable. Running the fork locally? Set fork IP to `127.0.0.1`. Otherwise ping the organiser.
• *Can't join a team you just ingested* → it needs a **fork restart**.
• *"Set your coach name first"* → do **step 2**.
• *Options missing / nothing happens* → you're on an old build; grab **v0.2.0+**.
