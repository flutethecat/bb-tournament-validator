# Sidebar icons: icons/nav

The left sidebar's top-level and Useful resources icons (spa/src/components/ShellNav.vue, names in spa/src/home/nav.ts),
drawn at 20 px beside each label and 24 px in the collapsed rail.

ATTRIBUTION: original Super FUMBBL site assets, drawn for this site (10-30) as 64 x 64 pixel art on a hard-edged grid in
the site palette (near-black outline, heading red, bone white, slate). Not copied from any other site, and nothing in them
is derived from Games Workshop or FUMBBL art. The resource icons are generic pictures (rulebook, video screen, pennant,
globe), not the linked sites' logos.
