# Sidebar icons: icons/nav

The left sidebar's top-level and Resources icons (spa/src/components/ShellNav.vue, names in spa/src/home/nav.ts),
drawn at 26 px beside each label and 30 px in the collapsed rail.

ATTRIBUTION: original Super FUMBBL site assets (redrawn 10-30): small retro overworld-item sprites drawn by hand as
16 x 16 pixel maps in tools/draw-nav-icons.py (run `python tools/draw-nav-icons.py` from apps/config-web to rebuild) and
upscaled x4 nearest-neighbour to 64 x 64 PNG masters with a transparent background. 1 px dark outline, 3-tone shading,
a restrained palette (greens, golds, browns, stone greys, blues; red only as a small accent). The 8/16-bit game look is
the inspiration; no sprite or asset is copied from any game, Nintendo, Games Workshop, TourPlay, FUMBBL or any other
property. The resource icons are generic pictures (rulebook, television, shield with a mountain, globe), not the linked
sites' logos.
